# Wen SaaS 使用与扩展文档

面向**基于底座开发业务**的开发者。建议阅读顺序：先跑起来，再看架构，然后按需查各接入指南。

仓内的 `module-crm_demo`（客户管理 Demo）是覆盖全部底座能力的可运行样板——下面每篇接入指南讲到的能力都能在它里面找到对应示例，拿不准照抄即可。
